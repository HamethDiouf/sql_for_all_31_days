# 🚀 SQL for All - Challenge 31 Jours

Bienvenue sur mon dépôt de suivi du challenge **SQL for All (31 jours)** ! Ce projet a pour objectif de consolider et d'approfondir mes compétences en SQL et en manipulation de bases de données à travers des exercices pratiques quotidiens.

---

## 📂 Structure du Projet

Le projet est organisé par jour pour faciliter la lecture et le suivi de la progression :

```text
sql_for_all_31_days/
│
├── .vscode/             # Configuration de l'éditeur
├── database/            # Scripts globaux (création, schéma, seed, reset)
├── day_01/              # Jour 1 : Introduction au SELECT et création de table
│   ├── challenge.md
│   └── solution.sql
├── day_02/              # Jour 2 : Alias, projections et DISTINCT
│   ├── challenge.md
│   └── solution.sql
├── ...                  # Jours 03 à 31
├── resources/           # Ressources et datasets du challenge
├── PROGRESS.md          # Suivi global de l'avancement
└── README.md            # Documentation du projet
